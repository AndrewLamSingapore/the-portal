# Portal V2 release gate

A V2 release is acceptable only when:

1. `npm run verify` passes.
2. The evidence model never permits AI generation to mark itself historically verified.
3. Generated source trails contain no invented URLs.
4. Existing Shared Stacks remain readable after the additive schema migration.
5. Temporal graph, exhibitions, relationship traversal and serendipity APIs respond from the same archive.
6. The primary interface clearly labels AI-curated, verified and inferential material.
7. Production smoke verification remains enabled.
8. `npm run smoke:v2` passes after deployment.

A dedicated domain is a separate public-identity release because purchasing a domain creates an external financial commitment.
