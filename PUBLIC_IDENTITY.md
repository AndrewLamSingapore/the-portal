# Public identity architecture

The product identity is **THE PORTAL · Living Knowledge Graph**.

Canonical product language:

> Not a record of what has been done. A living map of how encounters become connections, connections become experiments, and experiments create new ways of seeing the world.

The operating loop is:

> **ENCOUNTER → CONNECT → EXPERIMENT → EVOLVE ↻**

The interface and APIs contain no dependency on a future custom hostname. This means a dedicated domain can be attached without application changes. Until a domain is purchased, the existing Vercel hostname remains the technical canonical endpoint.
